# Windows installer storage

CI stages the x64 setup executable and portable ZIP in this directory before
uploading them. Published binaries live permanently in the matching versioned
GitHub Release; they are not committed to Git because they exceed normal
repository file-size limits.

For version 0.26.30, download the setup executable or portable ZIP from the
[`v0.26.30` GitHub Release](https://github.com/tpluharik/Tuxindrive/releases/tag/v0.26.30).
See [the release process](../../../docs/RELEASES.md) for signing and updater rules.
