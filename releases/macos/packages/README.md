# macOS installer storage

CI stages the DMG in this directory before uploading it. Published images live
permanently in the matching versioned GitHub Release; they are not committed to
Git because they exceed normal repository file-size limits.

For version 0.26.25, download the DMG from the
[`v0.26.25` GitHub Release](https://github.com/tpluharik/Tuxindrive/releases/tag/v0.26.25).
See [the release process](../../../docs/RELEASES.md) for signing and updater rules.
